# Din Cuptor

O aplicație web statică, în limba română, cu o rețetă recomandată pentru fiecare zi din următoarele 90 de zile. Include 31 de preparate de casă, instrucțiuni, ingrediente și navigare în calendar.

## Utilizare

Deschide `index.html` în browser. Nu sunt necesare instalări sau servicii externe pentru funcționalitate.

## Proiect

- `index.html` — structura și conținutul paginii
- `style.css` — stiluri responsive
- `app.js` — calendarul și catalogul de rețete
